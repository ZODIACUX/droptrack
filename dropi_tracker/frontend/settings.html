Configuración de la Sincronización Automática

Para que la sincronización automática funcione, la aplicación necesita acceder a tus credenciales de Dropi de forma segura. Por favor, configura las siguientes variables de entorno en el sistema donde se ejecuta la aplicación:

  • DROPI_EMAIL: Tu correo electrónico de inicio de sesión en Dropi.
  • DROPI_PASSWORD: Tu contraseña de Dropi.
  • SECRET_KEY: Una clave secreta larga y aleatoria para la aplicación.

Una vez configuradas, el botón "Sincronizar con Dropi" en la página principal utilizará estas credenciales para conectarse a la API de Dropi.
